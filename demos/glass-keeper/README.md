# Glass Keeper

Signature-technique code film for track **B**: ~5,184 glass and gold-leaf tiles that were never cemented. They assemble a pocket watch, become a lighthouse, lift into a gull flock, then spiral away.

## Watch / render

```bash
# previews + checks
node demos/code-film/shared/harness.mjs demos/glass-keeper/index.html --preview 4,10,15,25,36,46
node demos/code-film/shared/harness.mjs demos/glass-keeper/index.html --contact --check

# full MP4 (playable H.264 ≤4.1 + 720p preview)
node demos/code-film/shared/harness.mjs demos/glass-keeper/index.html --render
```

Interactive: open `index.html` and press Play.
