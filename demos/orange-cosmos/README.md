# Orange Cosmos

Signature-technique code film: a lonely orange square with a face breathes, multiplies on orbital paths, shatters into prism rainbow shards, spirals through a particle vortex, collapses into a lensing black hole, then pulls back to Earth from the Moon.

**Technique:** `orange-square-metamorphosis` — one continuous morph (overlapping phase envelopes), not slideshow dissolves. Zero assets. `seekPure: true`. Web Audio score from the same storyboard events.

Duration: **32s** @ 30fps · 1920×1080
