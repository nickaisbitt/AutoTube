# Tile Hatch

Night water of ~11,520 glass tiles. Star glints deform and hatch into a school of ~20 fish, gather into one great koi silhouette, then settle back to mosaic.

Signature technique: **tile-hatch-school**.

## Watch / render

```bash
node demos/code-film/shared/harness.mjs demos/tile-hatch/index.html --preview 3,12,22,32,42,50
node demos/code-film/shared/harness.mjs demos/tile-hatch/index.html --check

# full MP4 when ready
node demos/code-film/shared/harness.mjs demos/tile-hatch/index.html --render
```

Interactive: open `index.html` and press Play.
