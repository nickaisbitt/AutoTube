# AI Documentary Engine — build track

Status: active development branch `ai-documentary-engine`.

## Product contract

A single title is the only required user input. The engine autonomously researches,
writes, directs, generates all creative media, narrates, scores, edits, renders and
packages a complete 16:9 documentary MP4. The editor/UI is deliberately out of scope
for the first release.

"100% AI-generated" means every creative visual, narration track, music track and
sound effect is generated by an AI model. Deterministic software (FFmpeg, compositing,
captions, typography, charts, maps and timeline assembly) is permitted as production
infrastructure. Third-party stock, archive clips, web images and unlicensed music are
not permitted in this mode. Generated historical scenes must be labelled as
reconstructions and never presented as authentic archive footage.

## Build stages

1. **Research dossier** — source-linked claims, chronology, uncertainty and counter-evidence.
2. **Narrative script** — long-form structure, hook, chapter arcs, retention beats, measured target runtime.
3. **Visual bible** — style, period accuracy, character/environment continuity, shot grammar.
4. **Shot plan** — every narration beat mapped to a purposeful generated visual or original graphic.
5. **Generation** — generated still/motion assets with prompt, provider/model, timestamp, hash and cost provenance.
6. **Narration and score** — consistent licensed AI voice, generated music/SFX, forced alignment and mix.
7. **Assembly** — motion, transitions, subtitles, chapter cards, maps/charts, end card, thumbnail.
8. **Independent QA** — factual/claim audit, shot relevance, repetition, visual defects, audio, caption sync, rights/provenance.
9. **Repair loop** — regenerate only failed shots/lines; preserve passing assets.
10. **Release package** — MP4, SRT/VTT, thumbnail, chapters, description, sources, provenance manifest and QA report.

## First episode

**The Rise and Fall of the Roman Empire — How Rome Built a World That Still Exists Today**

Target: 25–30 minutes, 1080p, 16:9. This is the initial stress test, not a restriction on topic coverage.

## Acceptance gates

- No stock or scraped footage in AI-only mode.
- Every creative asset has generation provenance and SHA-256.
- Every material factual claim has source evidence; unresolved claims are labelled or removed.
- No synthetic scene is misrepresented as documentary evidence.
- Actual MP4 decodes; audio is present and intelligible; captions align to final narration.
- No repeated filler montage or still-image slideshow masquerading as cinematic video.
- Runtime is measured from final encoded output, not estimated from the script.
- No publication until rights, factual and platform-disclosure checks pass.

## Current implementation

- The existing AutoTube codebase already has a full render/voiceover/export path and a separate improvement/QA loop.
- Existing media acquisition is primarily external-source/stock oriented, so it cannot satisfy the strict AI-only contract as-is.
- Added `scripts/lib/ai-only-policy.mjs`, a fail-closed provenance gate, plus Node tests. This is the first integration primitive; the generation adapters and render integration remain to be implemented and tested.
